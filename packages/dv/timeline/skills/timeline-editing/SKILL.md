# Timeline editing

Resolve "clip N" first: it is the Nth clip by `start_sec` of track 0 (视频 1) in `video_tracks` of the first timeline in the project block, or of the track or timeline the user names. Read the clip's clip ID (such as `cl3`, the `clip` argument of every `dv_timeline_clip_*` call except add), its `start_sec`, its asset ID, the record that produced it, that record's `modality`, `task`, `provider` and `model`, and, for a shot that continued the previous one, the record it continued from. `reason` is required on every call. Deterministic calls (timeline edits, export, still) and reads (`dv_inspect_asset`, `dv_inspect_image`) run at once; a render that the user asked for by name runs at once; anything you propose yourself is described and left for the user to agree to, with the question in bold.

| User says | Calls, in order | Required arguments |
| --- | --- | --- |
| "trim X s off the start of clip N" | `dv_timeline_clip_trim` | `clip` = clip N's clip ID, `in_sec` = X (default 1.0 when unspecified; say so), `out_sec` = the clip's current out point when it has one. The clip file stays unchanged. |
| "trim X s off the end of clip N" | `dv_inspect_asset` → `dv_timeline_clip_trim` | inspect: `inputs.asset` = clip N's asset (read `duration_sec`). trim: `clip` = clip N's clip ID, `in_sec` = the clip's current in point when it has one, `out_sec` = duration − X. |
| "keep only A s to B s of clip N" | `dv_timeline_clip_trim` | `clip` = clip N's clip ID, `in_sec` = A, `out_sec` = B. The clip file stays unchanged. |
| "a different angle for clip N", "another take", "redo it" | `dv_shot_render` → `dv_timeline_clip_replace` | render: `modality`, `task`, `provider` and `model` = same as the record that produced clip N (the base record), `prompt` (only the named change differs from the base), `based_on` = the base record, `supersedes: [the base record]`, `duration_sec` = same; for task `ref2v` also `inputs.reference` = same as the base record (usually `["c1@1"]`) and `continue_from` = same as the base record when it had one. replace: `clip` = clip N's clip ID, `asset` = output #0 of the new record. The old take stays available. |
| "change the person", "make this person look like this image" | `dv_asset_import` → the update tool of the reference's kind → report stale → (after the user chooses) retakes | import: `path`, `mime`. update: the arguments that the kind's skill gives, with `inputs.reference` = [new asset ID]. Then list the stale shots and ask in bold; redo only the agreed ones as retakes with `inputs.reference` = `<id>@<new version>`. |
| "change the style", "add film grain" | the create (or update) tool of the reference kind that holds a look → propose retakes | create: the arguments that the kind's skill gives. Add `<id>@<version>` to `inputs.reference` of each task `ref2v` retake and cite its reference images in the prompt; retakes need the user's agreement, asked in bold. |
| "move clip N to X s", "move it to video 2", "put clip A after clip B" | `dv_timeline_clip_move` | `clip` = clip A's clip ID, `start_sec` = X (after clip B: B's `start_sec` plus its length), and `track` when the track changes. The other clips keep their times, so nothing makes room: when the clip would overlap another clip of the track, the call is refused; pick a free time or another track and say which. When a moved shot or the shot after it continued its previous shot, say that the join may not be continuous and offer a retake. |
| "delete clip N" | `dv_timeline_clip_remove` | `clip` = clip N's clip ID. The other clips keep their times, so a gap stays where it played; say so. |
| "add a clip after clip N", "put this shot on video 2 at X s" | `dv_shot_render` when the shot does not exist yet → `dv_timeline_clip_add` | render: `modality`, `task`, `provider` and `model` (usually those of clip N's record), `prompt`; for task `ref2v` also `inputs.reference`, and `continue_from` = the record that produced clip N when the new shot continues it. add: `timeline`, `asset` = output #0 (after `dv_proj_wait`), `track` (0 for 视频 1, the one after the last for a new track), `start_sec` = where clip N ends, or X. A clip must not overlap another clip of its track; when the time is taken, use the end of the last clip of the track or another track and say which. |
| "go back to the previous take of clip N" | `dv_timeline_clip_replace` | `clip` = clip N's clip ID, `asset` = the earlier take's asset (from the takes in the project block). No render. |
| "undo", "go back one step" | `dv_proj_undo` | none: it goes back one step and adds no step. |
| "redo", "I undid that by mistake", "bring back what I undid" | `dv_proj_redo` | none: it goes forward one step after an undo and adds no step. |
| "roll back", "go back to before …", "undo back to …", "go back to the previous version" (the project, not one clip) | `dv_proj_history_list` → `dv_proj_undo` | list: find the record of the step to go to (`place` `before`, or `after` for a step that an earlier move left). undo: `to` = that record ID; the project shows its state just after it, and the move adds no step. A new change after a move discards the later steps for good, so ask first when the user may still want them. Never rebuild the earlier state with new edits (clip replaces). |
| "show me the last frame of clip N", "the frame at t s" | `dv_asset_grab_still` → `dv_inspect_image` when a judgment is needed | still: `inputs.video` = clip N's asset, `at` = `last`, `first`, or a number of seconds (never a numeric string). inspect: `inputs.image` = the still asset, `question`. |
| "mute the video's sound", "remove the original audio", "mute sound track N", "mute video track N" (or "unmute …") | `dv_timeline_mute` | `timeline`, `target` = `video_track` for the own audio of one video track's clips (track 0 for 视频 1, which is "the video's sound" when the user names no track) or `sound` for a sound track, `track` = its number (from `video_tracks` or `sound_tracks`), `muted` = true (false to unmute). Muted audio is left out of the export: the own audio of a muted video track's clips, and the sounds of a muted sound track. |
| "turn the music down", "the background is too loud", "make the narration louder" | `dv_timeline_volume` | `timeline`, `target` = `sound` for a sound track or `video_track` for the own audio of a video track's clips, `track`, `volume_db` from -40 to 0 (0 = as recorded; music under speech -18 to -12). Nothing can go above 0 dB, so to make one track stand out, lower the others. |
| "cut the music at X s", "split this sound at the playhead" | `dv_timeline_sound_split` | `sound` = the sound ID (from `sounds`), `at_sec` = seconds inside its asset: X minus the sound's `start_sec`, plus its `in_sec` (0 when null). Both parts stay where they played; to drop one, call `dv_timeline_sound_remove` with its sound ID. |
| "move the music to X s", "put the voice on sound track N", "cut the first X s of the music" | `dv_timeline_sound_move` / `dv_timeline_sound_trim` | Move: `sound`, `start_sec` = X, and `track` = N when it changes (an existing sound track or the one after the last). Trim: `sound`, `in_sec` and `out_sec` in seconds inside its asset (omit one to keep the asset's start or end); a new in point moves the sound's start along, so the rest plays where it did. |
| "add an empty video track", "add an audio track" | `dv_timeline_track_add` | `timeline`, `kind` = `video` or `sound`. The track goes under all the tracks; to put a clip or a sound on a new track, call `dv_timeline_clip_add` or `dv_timeline_sound_add` with the track after the last instead. |
| "put video 3 above video 2", "bring this track to the front", "move video 1 down a layer" | `dv_timeline_video_track_move` | `timeline`, `track`, `to`; where both tracks have a clip, the one with the lower number shows. 视频 N is `track` N − 1. |
| "delete video 1", "delete video track N" | `dv_timeline_video_track_remove` | `timeline`, `track` (0 for 视频 1); its clips go and every later track moves up one number, so say the new numbers. For one clip, use `dv_timeline_clip_remove` instead. |
| "put the timeline on the canvas", "show the timeline next to the shots" | `dv_timeline_place` | `timeline` = the timeline's ID. A timeline goes on the canvas once: a second call is refused with the ID of the node that shows it, so tell the user it is already there. |
| "put it together", "export the final video" | `dv_timeline_export` | `timeline` = the timeline's ID (default: the first timeline); it trims each clip with an in or out point to that range and plays every clip at its time, the lowest track number on top, black where no clip plays; then give the link. |

## Rules that apply to every row

- A retake keeps the base record's `modality`, `task`, `provider` and `model`. In task `ref2v`, copy the base record's references every time: the model's schema gives the reference count, and `fasth3` needs at least one. A task `t2v` retake takes no references.
- `supersedes` marks the records that used the old output stale (stills, exports). Nothing reruns by itself: list them and redo only what the user agrees to. When the user keeps a stale result as it is, call `dv_proj_stale_accept` with its record.
- After any render, `dv_proj_wait` then `dv_proj_state`, and report the last frame and link.
- When "clip N" or "this" fits two clips and the message names no reference (a `dv:` mention), ask.
- The editor shows video track `track` of `video_tracks` as 视频 `track` + 1 (视频 while it is the only video track), so "video track 2" or 视频 2 is `track` 1. Every video track works the same way: where a track has no clip, the track under it shows.
- Edits never move other clips: a removal or a shorter clip leaves a gap, and a clip that would overlap another clip of its track is refused.
