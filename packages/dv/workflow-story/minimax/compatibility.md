# DreamVerse Compatibility

These notes adapt tool names, not the selected skill's creative steps or approval requirements. The official skill is not evidence that a model or server is available.

- Load `video-model-selection`, then use `dv_models_list` and `dv_models_get` to check the available modality, task, provider, model, inputs and limits. Load the chosen model's prompting skill if required. Do not send Hub-only parameters to DreamVerse tools. H3 requests can use the existing `uniserve/fasth3` route only when its capabilities match the request; its `ref2v` task requires reference media. Ask for suitable input when it is missing. Never silently change models, duration, resolution or aspect ratio.
- For `hub_generate_image`, use `dv_image_generate` if available and suitable. For `hub_generate_video`, use `dv_shot_render` and `dv_proj_wait`. For speech or audio, use `dv_audio_generate` only if the selected audio model supports the requested content. A speech model does not imply a music-generation service. Video-native sound is usable only when the selected skill permits it and the video model supports it.
- For canvas text nodes and tables, use `dv_textnode_write` and `dv_textnode_read`; tables can be Markdown in text nodes. For existing media, use `dv_asset_import` and `dv_asset_place`. Outputs remain in the existing project, asset pool and canvas. Read `dv_proj_state` for project items. Hub-specific canvas grouping has no direct equivalent: disclose that outputs remain separate canvas nodes.
- For clip ordering, trimming and assembly, load `timeline-editing` and use its existing `dv_timeline_*` tools. Its re-encoding join fallback drops audio; do not claim a finished soundtrack without checking the export. Do not assume this supplies arbitrary Hub video edits, audio mixing/replacement, beat detection, music generation, transcription or burned-in subtitles. Those capabilities have no guaranteed mapping here.
- For image inspection, use `dv_inspect_image` only if present and supported by the Agent model. General Hub media analysis, image search, webfetch and delegated Hub tasks are not guaranteed by this Web preset. Ask for source files or verified information when needed; do not claim to have inspected or verified unavailable material.
- Preserve choice cards and hard approvals with the existing `ask_user_question` tool. If it is absent, ask in chat and stop until the user replies. A selected skill, a supplied reference or an earlier generic request to create a video is not approval for a later confirmation gate.
- Read required `references/` documents with `dv_minimax_read_reference`, using paths relative to the selected skill. Do not invent missing reference content.
- If a mandatory capability or model is unavailable, identify the requirement and the missing capability, offer the permitted pre-production outputs, and wait for the user's decision. Never silently skip it or claim the complete skill workflow succeeded. In particular, skills requiring separate music, beat-synced editing or subtitles may stop at pre-production in this deployment.
